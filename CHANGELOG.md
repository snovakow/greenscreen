# Changelog

Version Release Notes

## 0.6.0 - 2026-11-21

- Tint and saturation add-ons inside OBS's filter, before its spill, gamma, contrast and brightness, without changing which colours are keyed
- Saturation add-on in HSB: each colour keeps its hue and brightest channel, up to full saturation

## 0.5.0 - 2026-11-20

- Chroma key as in OBS Studio: OBS's keying, settings, ranges, defaults and preset colours, so a key tuned in OBS copies across as it is
- Hue-only spill add-on: takes only the key's hue off edges and hair, which keep their own colour rather than turning grey
